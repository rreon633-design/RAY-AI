# RAY AI — Sunrise Minimal On-Device Local Intelligence

  <img src="app/src/main/res/drawable/ic_launcher_foreground.xml" width="120" alt="RAY AI Logo" />

**RAY AI** is a state-of-the-art Android application designed for **100% private, on-device local AI inference** powered by GGML JNI bindings, quantized GGUF/INT4 models (Gemma 2, Qwen 2.5, MiniCPM, Llama 3), and a modern Jetpack Compose UI built with the **Sunrise Minimal** design system.

---

## Key Highlights

- **Sunrise Minimal Light & Dark Theme**: High contrast, elegant typography, generous white space, and warm accent palettes.
- **On-Device Local Inference**: Zero server dependency, complete offline privacy, and zero data leakage.
- **Dynamic HTML, CSS & JavaScript Sandbox**: Live interactive preview rendering of code generated by RAY AI.
- **Rich Markdown AI Responses**: Syntactic code highlighting, bold emphasis, tables, and blockquotes.
- **Local Model Manager**: Download and manage GGUF models directly on device with real-time progress bars.
- **Memory Engine**: Persist key user facts and instructions across sessions.
- **Hardware Benchmarking**: Benchmark CPU token generation speed (tok/s) and RAM utilization directly on Android devices.

## Quick Start

1. Clone or import the project into Android Studio.
2. Build and run on an Android device running **Android 8.0 (API level 26)** or higher.
3. Open the **Models** tab to download your first GGUF quantized model (e.g., Qwen 2.5 0.5B or Gemma 2 2B).
4. Start a new chat in the **Chat** screen and enjoy private local AI!
