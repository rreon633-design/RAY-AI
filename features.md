# RAY AI — Comprehensive Feature Catalog

## 1. Chat & Conversational AI

- **Streaming Token Delivery**: Real-time word-by-word token generation with smooth animations.
- **Markdown & Code Highlighting**: Automatic formatting of bold text, headers, lists, blockquotes, and language-specific code snippets.
- **Interactive HTML/CSS/JS Sandbox**:
  - Live preview modal for web code blocks generated by RAY AI.
  - Interactive web container rendering responsive designs, CSS styles, and JavaScript logic in real time.
- **Session Management**:
  - Create new chat threads instantly.
  - Switch between active conversation histories.
  - Delete individual threads or clear all sessions.
- **Stop Generation Control**: Instantly interrupt model output mid-token via the unified stop button.
- **Attachment & File Drawer**: Quick access drawer to attach text context or local files.

---

## 2. Model Management Center

- **On-Device GGUF Downloads**: Download 4-bit quantized GGUF models directly from HuggingFace / GitHub releases.
- **Real-Time Progress Tracking**: Visual progress bars showing percentage, MB downloaded, and remaining time.
- **Model Switching**: Dynamically switch active model (Gemma, Qwen, MiniCPM, Llama) with a single tap.
- **Storage Management**: Inspect file size on disk and delete model weights to free up device memory.
- **Category Filters**: Filter models by *General*, *Coding*, *Fast*, or *Reasoning*.

---

## 3. Custom Memories Engine

- **Persistent Facts Storage**: Store user preferences, developer constraints, or custom instructions across sessions.
- **Automatic Context Injection**: Saved memories are automatically prepended to system prompts prior to inference.
- **Memory Management**: Add new memory items, delete individual entries, or clear all facts.

---

## 4. Hardware Benchmarking & CPU Tuning

- **Token Generation Speedometer**: Measure tokens per second (tok/s) during active inference.
- **CPU Thread Control**: Map inference across 1, 2, 4, 6, or 8 CPU cores based on device thermals.
- **Context Window Adjustment**: Configure context history length (512, 1024, 2048, 4096 tokens).
- **Temperature Slider**: Adjust response creativity from 0.1 (Precise/Code) to 1.2 (Creative).

---

## 5. UI Customization & Diagnostics

- **Sunrise Minimal Theme**: Clean light layout by default, with dark mode toggle and system default integration.
- **Notifications & Alerts**: Configure model completion alerts, RAM usage warnings, and daily summaries.
- **Diagnostic Bug Reporting**: Submit categorized feedback and diagnostic tickets directly in app settings.
- **About & Privacy**: View offline privacy guarantees and engine specs.
