# RAY AI — User & Developer Usage Guide

Welcome to **RAY AI**! Follow this guide to get the best performance from on-device local AI.

---

## 1. Initial Setup & Model Downloading

1. **Launch App**: Open RAY AI on your Android device.
2. **Navigate to Models Tab**: Tap the **Models** icon in the bottom navigation bar.
3. **Download Model**:
   - For fast responses: Download **Qwen 2.5 0.5B** (~390 MB).
   - For coding & reasoning: Download **Gemma 2 2B** (~1.4 GB) or **MiniCPM 4B** (~2.1 GB).
4. **Monitor Progress**: Watch the real-time download progress bar. Once completed, the badge will change to **Downloaded**.

---

## 2. Starting a Local Chat Session

1. Tap the **Chat** icon in the bottom navigation bar.
2. **Select Active Model**: Tap the model selector pill at the top (e.g. *Qwen 2.5 0.5B*) and pick your preferred downloaded model.
3. **Type Prompt**: Enter your query in the bottom input bar and tap **Send**.
4. **Code Rendering & HTML Sandbox**:
   - Code blocks automatically format with copy buttons.
   - If RAY AI generates HTML/CSS/JS code, tap the **Render Web** button to preview interactive web interfaces in real time.
5. **Stop Generation**: Tap the square **Stop** button at any time to freeze token output.

---

## 3. Managing AI Memories

1. Tap **Settings** in the bottom navigation or tap the **Three Lines Menu** in Chat.
2. Scroll to **AI Memories & Stored Facts**.
3. Type a fact (e.g. *"I am building an Android app with Jetpack Compose"*) and tap **Add**.
4. RAY AI will automatically remember this fact across all future chat sessions!

---

## 4. Theme & Appearance

1. Go to **Settings** -> **Appearance & Theme**.
2. Select **Light Mode** (Sunrise Minimal Light), **Dark Mode** (Sunrise Dark), or **System**.
3. The UI will instantly transition across all screens.

---

## 5. CPU Performance Tuning

- **CPU Threads**:
  - Set to **4 Threads** for balanced speed and battery usage.
  - Set to **6-8 Threads** for maximum token output speed.
- **Temperature**:
  - Set to **0.2 - 0.4** for strict coding and factual answers.
  - Set to **0.7 - 0.9** for creative writing and brainstorming.
